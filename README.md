# Mochi's Cheat - 自動テスト解答ツール

このツールは、画面上のテスト問題を自動的に解答するためのアプリケーションです。

## 特徴

- **ローカルLLM使用**: Ollama + llama3.2-visionモデルを使用し、APIキー不要・トークン料金なし
- **オフライン動作**: インターネット接続不要で動作可能
- **画像認識**: 画面をキャプチャして問題文と選択肢を理解
- **自動操作**: 正解を選択してボタンをクリック

## 必要な環境

- Python 3.8以上
- Ollama（ローカルLLMランタイム）

## インストール手順

### 1. Ollamaのインストール

#### Windows
```bash
# https://ollama.ai/ からインストーラーをダウンロードして実行
```

#### macOS
```bash
brew install ollama
```

#### Linux
```bash
curl -fsSL https://ollama.ai/install.sh | sh
```

### 2. ビジョンモデルのダウンロード

```bash
ollama pull llama3.2-vision
```

### 3. Ollamaサーバーの起動

```bash
ollama serve
```

別のターミナルで実行し、バックグラウンドで動作させておきます。

### 4. Pythonパッケージのインストール

```bash
pip install pillow mss pyautogui requests
```

## 使用方法

### app.py - 問題解答表示アプリ

画面上の問題を解析して答えを表示します。

```bash
python app.py
```

1. アプリケーションウィンドウが開きます
2. 「解説も詳しく表示する」チェックボックスで詳細モード/簡易モードを選択
3. 「📸 画面内の問題をすべて解く」ボタンをクリック
4. 画面がキャプチャされ、AIが問題を解析して結果を表示

### auto_solving.py - 自動周回アプリ

問題を解答して自動的にクリック操作を行います。

```bash
python auto_solving.py
```

1. アプリケーションウィンドウを画面の隅に配置
2. 「▶ 自動周回スタート」をクリック
3. AIが自動的に問題を解いてクリック操作を実行
4. 停止する場合は「■ 停止」ボタンをクリック

**注意**: 自動操作中はマウスに触れないでください。緊急停止はマウスを画面左上に移動してください。

## トラブルシューティング

### Ollama APIエラー

```
Ollama API呼び出しエラー
```

→ Ollamaサーバーが起動しているか確認してください: `ollama serve`

### モデルが見つからない

```
model 'llama3.2-vision' not found
```

→ モデルをダウンロードしてください: `ollama pull llama3.2-vision`

### 動作が遅い

- 初回実行時はモデルのロードに時間がかかります
- GPUがある場合、Ollamaが自動的に使用します
- CPU環境でも動作しますが、処理時間が長くなります

## 以前のバージョン（Gemini API使用）からの移行

以前のバージョンではGoogle Gemini APIを使用していましたが、トークン使用料の問題があったため、
ローカルLLM（Ollama）に移行しました。

**利点**:
- ✅ APIキー不要
- ✅ トークン使用料なし
- ✅ オフライン動作
- ✅ プライバシー保護（データが外部に送信されない）

**欠点**:
- ❌ 初回セットアップが必要
- ❌ ローカルマシンのリソースを使用
